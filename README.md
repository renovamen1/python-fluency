# Python Fluency

This repository contains my Python learning notes, drills, and mini projects across core language topics, NumPy, object-oriented programming, and basic machine learning workflows.

## Repository structure

- `Python Fundamentals/` — syntax drills and function/recursion practice
- `Numpy Basics/` — NumPy fundamentals and array practice notebooks
- `OOPS/` — OOP concepts and exercises in notebooks and scripts
- `file handling/` — file I/O drills and exercises
- `Basic projects in python/` — applied practice projects
- `my own pandas library/` — OOP-based data/model utility experiments
